# 🐹 Хомячковая Вселенная

Бесконечная симуляция размножения хомячков во времени!

## 🌟 Особенности
- ⏱️ Таймер отсчитывает время с момента загрузки
- 🐹 Каждую секунду добавляется новый хомячок
- 🚀 Можно ускорять размножение (x2 каждый раз)
- 🎯 Добавлять +100 хомячков по клику
- 🌌 Вместимость: 10,000,000,000,000,000,000+ хомячков
- 📱 Полностью адаптивный дизайн

## 🚀 Развертывание на Vercel

1. Создайте репозиторий на GitHub
2. Загрузите все файлы проекта
3. Перейдите на [Vercel](https://vercel.com/)
4. Импортируйте репозиторий
5. Деплой автоматический!

## 🛠 Технологии
- HTML5
- CSS3 (Grid, Flexbox, анимации)
- Vanilla JavaScript (ES6+)
- BigInt для работы с большими числами
