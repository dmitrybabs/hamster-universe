# 🛋️ Таймер Пинания Хуев

Честный счётчик времени, проведённого в продуктивном безделье.

## ✨ Особенности

- ⏱️ **Точный отсчёт времени** в днях, часах, минутах и секундах
- 🎭 **Анимированный персонаж**, который демонстрирует процесс
- 📊 **Статистика безделья** с научным подходом
- 🏆 **Система рекордов** с сохранением в браузере
- 🎯 **Простой интерфейс**: старт, пауза, сброс
- 📱 **Полностью адаптивный дизайн**

## 🚀 Как использовать

1. Откройте сайт
2. Нажмите "Начать пинать хуи"
3. Наблюдайте, как растёт время вашего безделья
4. Используйте паузу при необходимости
5. Поставьте личный рекорд!

## 📈 Что отслеживается

- **Общее время безделья**
- **Затраты энергии** (минимальные)
- **Мыслительная активность** (стремится к нулю)
- **Эффективность процесса** (растёт со временем)

## 🎨 Визуализация

- Анимированный человечек "пинает" шарики
- Количество шариков растёт со временем
- Цветовая индикация состояния
- Анимации при достижении рекордов

## 🛠 Технологии

- HTML5
- CSS3 (Grid, Flexbox, анимации CSS)
- Vanilla JavaScript (ES6+)
- LocalStorage для сохранения рекордов
- Font Awesome иконы
- Google Fonts
